# 검수 — 칸마다 써야 할 글자와 같은가

`review/<장>.png`: 칸마다 손글씨, 오른쪽 위 파란 글자 = 그 칸에 써야 할 글자, 왼쪽 아래 회색 = 칸 자리(행열, 예 `24` = 3번째 줄 5번째 칸).

## 틀림으로 보는 것
- 다른 글자다(받침이 다름, 모음이 다름, 획이 빠지거나 더해짐).
- 흔한 실수: ㅠ·ㅛ 를 다리 하나로(=ㅜ·ㅗ), ㅁ 을 동그랗게(=ㅇ), 받침 ㅅ 을 ㅆ 으로, ㄻ·ㄶ 을 ㄼ·ㄹㅎ 로, ㅐ·ㅔ·ㅙ·ㅞ·ㅖ 의 세로획 빠짐, ㅑ·ㅕ 의 짧은 획 하나.
- 칸 밖으로 많이 넘쳐 잘렸거나, 두 글자가 한 칸에, 빈 칸.
- 글씨체가 견본과 눈에 띄게 다름(갑자기 활자 같음, 굵기가 확 다름).

## 틀림이 아닌 것
- 손글씨다운 작은 흔들림, 크기 차이, 살짝 기운 것.
- 부호 장(sym)에서 쉼표·마침표가 작고 아래에, 「·“ 가 위에 있는 것 — 일부러 그렇게 쓰게 했다.

## 적는 법 (`errors.json`)
```json
{ "s07": { "24": "?", "31": "쬐" } }
```
- `"?"` = 버림. 그 글자는 다시 쓰기(`redo`)로 간다.
- 다른 음절이 또렷하게 쓰였으면 그 음절을 적는다 — 그 칸이 그 음절의 글자로 쓰인다(원래 글자는 여전히 없음).
- 사람용 페이지 `review/index.html` 에서 칸을 눌러 고르면 아래에 이 JSON 이 만들어진다.
- 에이전트가 제안한 것은 사용자가 페이지에서 확인한다. 에이전트 혼자 확정하지 않는다.
- 칸 그림(200px)으로 애매하면 `node scripts/hf.mjs compare <dir> s12:01 …` 로 크게 보고, 활자 참조가 있는 장은 그 아래 활자와 맞춰 본다.

## 일관성
장마다 글씨 높이·굵기가 크게 다르면(예: 어떤 장만 굵다) 그 장 전체를 다시 받는 게 낫다. 폰트에서 그 장 글자만 튀어 보인다.
