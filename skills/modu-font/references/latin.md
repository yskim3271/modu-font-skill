# 영문 더하기 (`--latin` · `latin <dir>`)

한국어·일본어 폰트에 같은 손글씨의 영문을 넣는다. 그리는 장은 폰트 종류와 상관없이 같은 3장이다.

| 장 | 칸 |
|---|---|
| L1 | A a B b … R r (대소문자 짝 18쌍) |
| L2 | S s … Z z + 부호 20 (`! ? . , : ; ' " ( ) [ ] { } - _ / \ \| &`) |
| L3 | 부호 18 (`@ # $ % * + = < > ^ ` ~ “ ” ‘ ’ – —`) + 크기로만 갈리는 짝 한 번 더(C c O o S s V v W w X x Z z P p K k) |

숫자는 본문 부호 장(sym)에 이미 있다. 폰트에 이미 있는 부호(한국어 sym 의 `, . ? ! ~ ( ) - : % /`, “ ” ‘ ’)는 그쪽이 이긴다 — 한글 옆에서 쓰던 모양이 바뀌지 않게.

## 순서
1. 새 폰트: `init <dir> … --latin`. 이미 있는 작업 폴더: `latin <dir>`.
2. `jobs <dir>` — 영문 첫 장 확인 전에는 **L1 하나만** 묶는다. ref-2 는 안내선 빈 격자(`style/latin-grid.png`).
3. 그리기(B·C, 돈 규칙 그대로) → `cut <dir> L1` → 검수 → 사용자와 확인.
4. 기준에 맞는 첫 영문 장은 `style/latin-format.png` 가 되고, `jobs` 를 다시 돌리면 L2·L3 이 그 장을 형식 참조로 묶인다.
5. 검수 → `redo`(빠진 영문은 영문 다시 쓰기 장 — 끝 6칸은 기준선을 잴 글자) → `glyphs` → build → `bold` → build --bold → `preview`(영문 줄이 함께 나온다).

## 같은 손글씨의 다른 폰트에 옮기기
한국어 폴더에서 L1~L3 을 받았으면 일본어 폴더는 다시 그리지 않는다:
`latin <일본어 폴더> --from <한국어 폴더>` → `cut <일본어 폴더> L1 L2 L3` → glyphs → build. 받은 그림과 그 장의 검수 결과(errors.json)를 옮긴다. 영문 크기·기준선은 영문끼리 정하므로 두 폰트의 영문은 같은 모양이 된다.

## 다른 곳에서 만든 폰트에 더하기 (`--base`)
이 스킬의 작업 폴더가 없고 글자 그림 목록(`glyphs.json` 형식 — 예: 이 스킬보다 먼저 쓰던 도구로 만든 폰트)만 있을 때:
`init <dir> --sample 견본.png --family-en … --family-ko … --style "…" --latin --base <glyphs.json> [--base-bold <glyphs-bold.json>]`.
바탕 글자는 그리지 않고 그 크기 기준을 그대로 쓴다(`--base-bold` 를 주면 굵은 판도 그 그림 그대로). 장은 영문(과 다시 쓰기)만 생긴다.

## 조립이 하는 일 (build_font.py)
- **크기**: 영문 대문자 잉크 높이 중앙값 → 640(1em=1000). 소문자 크기는 그린 비율 그대로.
- **기준선**: 장마다 기준선 글자(H n o x …) 아래 끝의 중앙값을 그 장의 기준선(0)으로 잰다 — 모델이 안내선을 조금 비켜 써도 맞는다. 그다음 글자별로 붙인다: 꼬리 없는 글자·숫자·`! ? . %` 는 잉크 아래 끝을 0 에, `g p q y` 는 위 끝을 x-높이에. 어긋남이 대문자 높이의 20% 를 넘으면 그대로 두고 알린다(검수에서 볼 것). `J Q j` 와 괄호·쉼표·따옴표는 칸에서 옮긴 자리 그대로.
- **옆 여백**: 곧은 기둥 쪽 50, 둥근 쪽 32, 열리거나 빗긴 쪽 14.
- **커닝**: 글자 옆모습(위아래로 조금 넓혀 빗긴 틈까지)의 가장 좁은 틈을 `o o` 틈에 맞춰 좁힌다(최대 대문자 높이의 18%, 15 단위 미만은 버림). `kern` 기능으로 들어간다.
- **줄 간격은 그대로**: 한국어·일본어 줄 간격(hhea 880/−120)을 바꾸지 않는다. 꼬리는 그 아래로 내려가도 화면에서 잘리지 않고, Windows 는 −250 아래를 자르므로 넘으면 경고한다. OS/2 에 x-높이·대문자 높이를 적는다.

## 검수에서 볼 것
- **대소문자**: 칸 하나만 보면 크기로만 갈리는 글자 — c/C, k/K, o/O, p/P, s/S, u/U, v/V, w/W, x/X, z/Z. 옆 칸 짝과 비교한다(L1·L2 는 대문자 바로 옆이 소문자). 틀렸으면 `"?"`(L3 의 같은 짝이 대신 쓰인다).
- **기준선**: 글자가 실선 위에 서 있나, `g j p q y` 꼬리가 실선 아래로 내려갔나.
- **비슷한 글자**: l / I / 1 / |, O / 0, ' / ‘ / ’, " / “ / ”, - / – / —(길이).
- **필기체로 이은 획**·활자 같은 모양이 나오면 그 장을 다시 받는다.
