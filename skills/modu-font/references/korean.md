# 한국어 모드 (`--script ko`, 기본)

한글(KS X 1001 2,350자) 폰트를 만든다. `--script` 를 안 주면 이 모드다(`--script korean` 도 된다). 일본어는 `references/japanese.md`, 영문 더하기는 `references/latin.md`.

## 장 구성
| 장 | 칸 |
|---|---|
| s01 … | 한글 36자씩. 차례는 `assets/ks2350-order.txt`(자주 쓰는 글자 먼저) — `--count 500` 이면 앞 500자, 기본 2,350자 |
| sym | 말풍선에 필요한 부호·채팅 낱자모·숫자 36자: `, . ? ! … ~ 「 」 “ ” ‘ ’ ㅋ ㅎ ㅠ ㅜ ㄷ ㅇ ♡ ♪ ( ) - : 0–9 % /` |

- 마지막 한글 장의 빈칸은 목표 다음 글자로 채운다(같은 값에 글자가 더 생긴다). 2,350자면 그 장 글자를 돌려 쓴다(겹친 칸은 앞 것만 쓴다).
- 글자 수와 장: 500자 = 한글 14장 + 부호 1장(약 $6), 2,350자 = 66장 + 부호 1장(약 $30) + 다시 쓰기 몇 장.

## 프롬프트가 하는 일
- 한 칸에 한 음절, 칸 높이의 약 60%, 크기를 고르게.
- **자모 풀이**: s13 부터(드문 글자가 나오는 장) 장마다 음절을 자모로 풀어 적어 준다(`쬐 = ㅉ + ㅚ`). 시트에 쓰지 말라고 하고, ㅠ·ㅛ 획 수, ㅑ·ㅕ 곁획, 겹받침 두 자음의 차례를 다시 짚는다.
- **부호 장**: 부호를 한글 한 칸 크기의 상자 안, 한글 옆에 올 자리·크기로 쓰게 한다(쉼표·마침표는 아래 왼쪽, 「 」 “ ” 는 위쪽, 낱자모는 음절의 70%).
- **다시 쓰기 장**(`redo`): 틀렸던 글자만 모아 여러 번 쓰게 하고 흔한 실수 목록을 붙인다. `--print` 면 같은 칸 배치의 활자 그림(ref-3)을 넣어 자모 구조만 참고하게 한다(활자 모양은 따라 하지 말라고).

## 검수에서 볼 것 (실측에서 나온 실수)
모두의 둥글펜 2,350자 첫 시도 1,872칸 중 63칸이 틀렸다(500자 시험은 432/432).
- ㅠ·ㅛ 를 다리·획 하나로(→ ㅜ·ㅗ)
- ㅁ 을 동그랗게(→ ㅇ)
- 받침 ㅅ 을 ㅆ 으로
- 겹받침 ㄻ·ㄶ 을 ㄼ 으로
- ㅐ·ㅔ·ㅙ·ㅞ·ㅖ 의 세로획 빠짐
기준과 errors.json 쓰는 법은 `references/review.md`.

## 조립 (build_font.py)
- 크기: 한글 잉크 높이 중앙값 → 780(1em=1000), 칸 안 세로 자리는 그대로(쉼표는 아래, 「 는 위).
- 옆 여백: 한글 45, 그 밖 35.
- 이름: `--family-en`(영어·Mac·파일 이름) + `--family-ko`(한국어 Windows 글꼴 목록). Windows 한국어 코드 페이지(완성형) 표시를 켠다 — 없으면 한국어 Windows 앱이 한글 글꼴로 안 보여 준다.
- 한 굵기 조립에 10분 넘게 걸릴 수 있다(2,350자).

## 이미 만든 한글 폰트에
- 영문 더하기: `latin <dir>` (`references/latin.md`).
- 이 스킬의 작업 폴더 없이 글자 그림 목록(glyphs.json)만 있으면 `init … --latin --base <glyphs.json>`.
- 같은 손글씨로 일본어 폰트: `drafts --base` 로 일본어 견본부터(`references/japanese.md`).
